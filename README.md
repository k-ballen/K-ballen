## 🔬 Current Project

### 🧠 EmkiWear — Parkinson's Tremor Monitoring System

My current thesis project focuses on developing a wearable system designed to monitor and analyze tremor in people with Parkinson's disease.

The project integrates:

* 📡 **Embedded systems and wearable technology**
* 📈 **Motion and tremor signal acquisition**
* 🧮 **Signal processing and data analysis**
* 📱 **Mobile application development**
* ☁️ **IoT and cloud technologies**
* 🩺 **Biomedical engineering**

The **EmkiWear** application is being developed as part of the project to provide users with a platform for recording, monitoring, and visualizing relevant information related to tremor and daily activities.
